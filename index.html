Patient Intake Demo

Imagine this is an EHR system that integrates the Squire Intake SDK. Patient intake has three parts: Schedule (SDK methods), Configure (intake settings widget), and Use (intake summary widget).

Connect to Squire

Paste your JWT access token to initialize the SDK.

Schedule an Intake Session

Use SDK methods to create an intake session and generate a link for the patient. The patient receives this link before their appointment.

SDK Code

// Create an intake session via SDK
const session = await squire.intake.createSession({
  intakeConfigId: 'config-uuid-from-settings-widget',
  appointmentDt: new Date('2026-06-15T10:00:00'),
  firstName: 'Jan',
  lastName: 'de Vries',
  email: 'jan@example.com',
  phoneNumber: '+31 6 1234 5678',
});

console.log(session.intakeUrl);  // Link for the patient
console.log(session.id);         // Track the session

Configure Intake Settings

The intake-settings widget lets HCPs configure which FHIR Questionnaires are used for intake. Embed this widget in your EHR settings page.

Embed Code

// Mount the intake-settings widget
const widget = squire.mountWidget(
  '#squire-intake-settings',
  'intake-settings',
  {
    locale: 'nl',
    theme: {
      colorPrimary: '#337ab7',
      colorDark: '#212529',
      colorLight: '#236aa7',
      colorLightest: '#f8f9fa',
      borderRadius: '1rem',
    }
  }
);

widget.on('loaded', () => {
  console.log('Intake settings widget loaded');
});

View Intake Summary

The intake-summary widget displays the completed intake data for the HCP. Embed this in the patient dossier or consultation view.

Embed Code

// Mount the intake-summary widget for a specific session
const summaryWidget = squire.mountWidget(
  '#squire-intake-summary',
  'intake-summary',
  {
    sessionId: 'int_a1b2c3d4e5f6g7h8',
    locale: 'nl',
    theme: {
      colorPrimary: '#337ab7',
      colorDark: '#212529',
      colorLight: '#236aa7',
      colorLightest: '#f8f9fa',
      borderRadius: '1rem',
      font: 'Roboto',
    }
  }
);

summaryWidget.on('loaded', () => {
  console.log('Intake summary loaded');
});
